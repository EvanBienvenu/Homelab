# Homelab DevOps

Projet personnel mené en parallèle de mon BTS SIO SISR pour atteindre un niveau Bac+3 DevOps.
L'objectif : construire pas à pas une chaîne DevOps complète, entièrement en machines virtuelles et décrite en code.

## Objectifs

- Infrastructure as Code : Vagrant, Ansible, Terraform
- Intégration et déploiement continus avec GitHub Actions
- Conteneurs avec Docker, puis orchestration avec Kubernetes (k3s)
- Supervision avec Prometheus et Grafana

## Environnement

- VirtualBox et Vagrant, sans serveur physique
- Ubuntu Desktop 26.04 LTS comme poste de travail
- Application fil rouge : une petite API Python avec FastAPI
